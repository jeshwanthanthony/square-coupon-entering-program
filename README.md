# Square Coupon Entering Program

Automates entering coupon codes into Square Marketing using Playwright.

## Usage

1. Install dependencies: `pip install playwright pandas`
2. Install the browser: `playwright install chromium`
3. Create a local `codes.csv` with a `code` column.
4. Run: `python square_coupon_bot.py`
5. Log in to Square in the opened browser, then press Enter in the terminal.

Do not commit coupon codes, browser profiles, or Square credentials.
